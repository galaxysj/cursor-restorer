# Cursor Restorer
Saves your cursor postion and restores with Command+Shift+R.  
<br>
<br>
## Key features
<img width="732" height="704" alt="2026-08-17 오후 5 21 30" src="https://github.com/user-attachments/assets/cdb269c1-568a-4e72-96ba-e31e3e8b2222" />

* Saves your cursor postion when when you are not moving the cursor for 1 second.   
* Command+Shift+R to Restore postion  
* Command+Shift+S to start/stop  
* Customizable hotkeys
